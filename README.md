## About Me

I'm a **Full Stack Developer** focused on building modern web applications with:

- **Frontend:** React, Next.js, JavaScript/TypeScript, Material UI, Tailwind CSS
- **Backend:** Java, Spring Boot, REST APIs
- **Persistence:** Spring Data JPA, Hibernate, SQL
- **Databases:** MySQL, Microsoft SQL Server, PostgreSQL
- **Engineering:** OOP, layered architecture, DTOs, validation, exception handling, transactions

I'm currently deepening my Java/Spring Boot skills by building backend projects from the ground up and turning them into production-style applications.

```text
Frontend        → React / Next.js
                    ↓
API             → Spring Boot / REST
                    ↓
Business Logic  → Service Layer
                    ↓
Persistence     → Spring Data JPA / Hibernate
                    ↓
Database        → MySQL / SQL Server / PostgreSQL
```
