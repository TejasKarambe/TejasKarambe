## 🌟 Featured Projects

### 💰 [ApexFinance — Enterprise Financial Engine](https://apex-finance-lilac.vercel.app/)
**Full-Stack Wealth & Budget Management Platform**

A production-grade, full-stack personal wealth and budget management engine built with a modern React frontend and a Spring Boot microservice backend.

- **Multi-Account Balances:** Track checking, savings, cash, and investments with real-time recalculations.
- **Zero-Sum Transfers:** Move funds between accounts without skewing monthly income and expense cash flow reports.
- **Proactive Budget Alerts:** Automated visual warnings when spending hits 80% and exceeds 100% of category limits.
- **Cash Flow Analytics & CSV Export:** Monthly income-vs-expense metrics, category leaderboards, and instant CSV ledger export.
- **Enterprise Security:** Spring Security with stateless JWT authentication and BCrypt password hashing backed by PostgreSQL (Neon).

> **Tech Stack:** React · Spring Boot · Java 21 · PostgreSQL (Neon) · Spring Security · JWT · Tailwind CSS · REST API · Vite  
> 🔗 **Links:** [Live Demo](https://apex-finance-lilac.vercel.app/) • [Frontend Repository](https://github.com/TejasKarambe/finance-client) • [Backend Repository](https://github.com/TejasKarambe/finance)
